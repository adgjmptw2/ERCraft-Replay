# 소스 스냅샷

2026-09-23에 12.4 대응 분석 코어와 별도 리플레이 서비스의 워커·뷰어에서 공개할 파일을 선별했다. 서비스 소스 전체나 운영 상태의 복제본은 아니다.

| sourceGroup | 구성 |
| --- | --- |
| `core-12.4` | 12.4 코어의 Python, 스키마, 정적 규칙·이미지 및 일부 정적 근거 |
| `worker-and-viewer` | 리플레이 서비스의 워커와 웹 뷰어 |
| `core-tests` | 공통 코어의 합성 입력 회귀 테스트 |

정확한 포함 목록과 SHA-256은 [SOURCE_MANIFEST.json](../SOURCE_MANIFEST.json)에 있다. 파일은 원본 바이트로 가져왔으며 공개 문서·검사 도구는 별도로 작성했다. `.gitattributes`는 Git의 자동 줄바꿈 변환을 막는다.

초기 디코더 계보는 [secret_replay](https://github.com/KimJaeGeun297/secret_replay)에서 시작한다. 이 저장소는 별도로 발전한 분석·서비스 소스의 스냅샷이며 원 저장소의 Git 이력을 가져오지 않았다. 새 라이선스를 임의로 부여하지 않는다.

gameDb ZIP, 비공개 생성 자료, 전체 release manifest 및 경기 근거를 생략했으므로 기존 운영 manifest와 이 공개 파일 집합은 동일하지 않다. 공개 목록의 해시 일치를 운영 환경 설치 검증으로 사용하면 안 된다.

원본 코어와 서비스 폴더는 수정하지 않았다. 이번 작업은 GitHub 소스 공개이며 서비스 배포를 수행하지 않는다.
