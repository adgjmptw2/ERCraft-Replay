# ERCraft-Replay 개발 현황 — 2026-09-26

## 공통 연결과 실제 출력

현재는 속도보다 데이터 품질을 우선합니다. GameDB의 91개 캐릭터·792개 스킬 그룹을 공통으로 참조하며, 캐릭터가 통째로 누락됐던 측정 항목 17개를 복원해 요청 목록을 90개 캐릭터·432개 항목으로 맞췄습니다. 나머지 1캐릭터는 해당 GameDB에 소유 스킬 그룹이 없습니다. 전체 데이터를 읽는 것과 모든 스킬의 명중 판정을 완성하는 것은 별개입니다.

연구용 공통 수집 경로도 복원된 목록을 사용하도록 연결했습니다. 중간 증거 캐시는 파일로 쌓지 않고 메모리에서 전달합니다. 3경기는 저장 패킷 재처리부터 피해량·스킬 계산, HTML·SQLite 저장까지 통합 확인했으며, 기존 보정 결과의 피해량과 스킬 주요 수치를 유지했습니다. 실제 출력에는 미확정 사용에 따른 조건부 적중률 범위를 추가하고, 통합 결과의 경기 번호 표시를 수정했습니다.

최신 분석 목록은 약 12KB의 참조 정보로 기존 결과를 연결하며 분석 본문을 중복 복사하지 않습니다. 원본과 분석 결과의 식별 정보·해시를 확인해 조회합니다. 9경기 중 3경기는 위 통합 경로를 확인한 결과이고, 나머지 6경기는 기존 산출물 검사를 통과한 결과입니다. 9경기 전체를 같은 최신 코드로 다시 처리했다는 뜻은 아닙니다.

## 현재 품질과 남은 작업

현재 선택한 9경기에는 75종의 캐릭터, 207명, 개인 교전 2,684개 구간과 스킬 지표 932개가 있습니다. 숫자로 제공되는 지표는 897개(관측 기반 537개·잠정 계산 360개)이며, 사용 관측 없음 24개, 교전 표본 없음 5개, 실행 대상 아님 2개, 판정 근거 미확정 4개가 남아 있습니다. 서로 다른 연구 프로필을 모은 결과이며, 숫자가 나온다는 사실이 독립적인 적중 정확도 검증을 뜻하지는 않습니다.

숫자 지표 중 11개 행에는 미확정 사용이 섞여 있습니다. 같은 스킬의 여러 측정 방식이 겹칠 수 있어 이를 독립된 사용 11건으로 합산하지 않습니다. 미확정 사용의 결과만 달라진다고 가정한 적중률 범위 폭은 약 3.8~14.3%p입니다. 이는 분류된 판정이 맞다는 조건의 범위이며, 검증된 오차범위나 통계적 신뢰구간이 아닙니다. 근거가 없는 결과는 빗나감이나 0으로 채우지 않습니다.

피해량은 교전 안팎의 합계 보존을 확인했지만, 종료 통계와 5% 넘게 차이 나는 결과 2건(가한 피해 +6.95%, 받은 피해 +10.44%)이 남았습니다. 5%는 큰 차이를 추리는 기준이며 모든 결과가 통과한 허용치가 아닙니다. 개별 교전의 정확도와 모든 스킬의 좁은 오차범위를 확보했다고 주장하지 않습니다.

현재 신규 다운로드와 성능 실험은 보류 중입니다. 아래의 30초 이내 기록은 이전 구성의 결과이며, 이후 VP 보정을 포함한 신규 처리에서는 35.804초가 걸렸습니다. 최신 구성의 안정적인 30초 목표는 아직 달성하지 못했습니다. 운영 배포도 수행하지 않았습니다.

C: 여유 공간은 최소 30GiB, 고유 projection의 저장량은 최대 5GiB로 관리합니다. 중간 파일 생성을 줄이고, 완료된 연구 파일은 내용 해시가 유지되는 무손실 압축으로 정리했습니다. 최신 Opus 검토는 HTTP 429 호출 제한으로 완료하지 못했으며 승인받은 변경으로 표현하지 않습니다. 이번 공개분은 Gemini 초안을 검토·수정한 진행 문서이며, 비공개 경기 자료와 최신 연구 실행 코드는 포함하지 않습니다.

## 데이터 정합성과 교전 분석

6경기·138명의 피해 사건 46,002건을 바탕으로 데이터 누락·중복·사건 식별 불일치에 대비한 공통 검사를 점검했습니다. 정상 입력의 기존 결과는 유지됐고, 인위적으로 넣은 누락·중복·건수 오류 36개 사례는 차단했습니다. 이 결과는 자료 전달과 집계의 일관성을 확인한 것이며, 서버의 개별 타격 정답을 증명한 것은 아닙니다.

일부 스킬 경로에서 적중 판단에 필요한 기록의 누락이 확인된 경우 이를 빗나감으로 단정하지 않도록 연구용 처리를 추가했습니다. 기록된 게임 종료 통계와 교전 중 추정한 피해량은 분리해 관리하며, 확인되지 않은 수치는 0으로 채우지 않습니다. HP 스냅샷을 활용한 추정은 아직 실험 단계입니다.

재사용할 수 있는 [공통 품질 모듈과 합성 입력 테스트](../research/quality/README.md)를 선별해 공개했습니다. 기존 서비스에 통합하거나 운영 배포한 변경은 아닙니다. 경기별 원본·개인 자료·인증 정보·게임 바이너리와 상세 실험 로그는 포함하지 않습니다.

## 이전 구성의 성능 기록

당시 동일 코드로 기존 검토 대상인 6경기(138명, 개인 교전 1,695개 구간)를 처리했습니다. 신규 프로세스 시작 및 다운로드부터 HTML·SQLite 결과 준비까지 **22.235~25.481초**가 걸렸으며, 6경기 모두 30초 이내였습니다. 이후 대표 경기 반복 실행도 **23.272초**에 끝났고, 실행 번호를 제외한 교전·스킬 분석 결과가 이전 실행과 완전히 같았습니다. 동일 코드로 총 7회 모두 30초 이내였습니다.

이는 이미 검토한 경기에서의 실측입니다. 별도의 미관측 경기 검증이나 모든 환경에서의 30초 보장을 의미하지 않습니다. OS·네트워크 캐시를 비우지 않았고, 결과 생성 후 수행하는 별도 검증은 측정 시간에서 제외했습니다. 연구용 실행 경로의 결과이므로 공개 모듈만으로 동일 실행을 재현할 수 있다는 뜻도 아닙니다.

## 이전 6경기 구성의 품질과 보관소 기록

이 수치는 규칙을 만들 때 참고한 같은 6경기의 결과이며, 자원 소모 5/9·소환물 귀속·상태 크레딧 연구 가정이 포함돼 있습니다. 아직 새 경기에서 검증한 결과는 아닙니다.

종료 통계 대비 가한 피해량 오차는 종료 피해가 0이 아닌 137명 전원 5% 이내(최대 4.791%, 95백분위수 2.281%)였습니다. 받은 피해량은 138명 중 137명이 5% 이내였으며, 1명은 10.440%의 예외 오차가 남았습니다. 미확정 사건이 있는 플레이어는 가한 피해 10명, 받은 피해 6명입니다. 종료 합계가 같더라도 개별 사건의 정확성을 증명하지는 않습니다.

스킬 604개 항목은 관측 기반 계산 366건, 실험적 계산 218건, 교전 표본 없음 2건, 시전 미관측 14건, 비실행 항목 1건, 근거 미확정 3건입니다. 수치 계산이 가능하다고 해서 독립적인 적중 정답이 증명된 것은 아닙니다.

경기별 분석 SQLite는 총 2,359,296바이트로 같은 내용을 담은 JSON 7,633,408바이트보다 약 69% 작습니다. 통합 색인은 32,768바이트이며 기존 저장 파일을 연결하므로 분석 본문을 복제하지 않습니다. 이 수치에는 원본 리플레이와 중간 projection이 포함되지 않습니다.

통합 조회는 원본 해시와 분석 버전이 모두 일치할 때만 결과를 반환합니다. 교전 합계·스킬 지표·큰 오차를 조회할 수 있으며, 중복 결과 충돌과 파일 손상을 감지합니다. 중복 등록·버전 불일치·결과 충돌·파일 손상 테스트를 통과했습니다. 저장 경로를 옮기면 색인을 다시 만들어야 합니다. 이 보관소와 최신 실행 경로는 로컬 연구 구현이며, 이번 공개 변경은 진행 문서 갱신입니다.
