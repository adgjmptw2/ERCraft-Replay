# 공개 자료 범위

## 포함

분석·일부 워커·뷰어 코드, 버전별 스키마와 계산 규칙, 공개 가능한 일부 정적 근거, 화면용 정적 이미지와 출처 메타데이터, 합성 입력 테스트를 포함한다.

## 획득 기능 비공개

악용 가능성을 줄이기 위해 원본 ER 파일 획득과 관련된 코드, 인증 연동, 다운로드 경로 및 사용 절차는 공개 대상에서 제외합니다. 공개 저장소는 이미 확보된 입력의 해석·분석·표시에 필요한 소스를 중심으로 제공합니다.

획득 구현과 구체적인 경로 정보는 공개 브랜치의 과거 커밋에서도 제거합니다. 기록을 다시 쓴 이후에는 새로 복제한 저장소를 사용하고, 이전 이력을 병합하거나 다시 푸시하지 않습니다. 이미 만들어진 외부 복사본이나 호스팅 서비스의 별도 보존 참조까지 삭제됐다는 의미는 아닙니다.

## 제외

- 원본 `.er` 리플레이, 획득 코드·인증 연동·다운로드 경로·사용 절차 및 경기별 분석 JSON
- 게임 데이터 ZIP, 설치된 게임 바이너리와 덤프
- 인증 토큰, 세션, 인증서, 비공개 계정 설정
- 운영 환경 파일, DB, 큐, 로그와 작업 중간 자료
- 개인 식별 정보가 들어 있는 경기 근거와 연구 보고서
- 모델 대화, 로컬 인계 문서와 운영 기록

이미지 및 게임 관련 명칭의 권리 정보는 [제3자 자료 안내](../THIRD_PARTY_NOTICES.md)를 참고한다.

## 결과 공개

`core/decoder/build_public_combat_analysis.py`와 공개 출력 검증기를 통과한 결과만 외부 화면에 연결한다. 원본 식별자, 인증 정보, 서명된 다운로드 URL과 비공개 증거를 그대로 공개하지 않는다.

미확인 값은 상태와 사유를 유지한다. 누락된 값을 다른 버전이나 다른 대상의 데이터로 대신하지 않는다.

## 원본 수명

취득한 `.er`는 분석에 필요한 동안만 임시 사용하며 성공·실패 후 정리한다. 원본 리플레이를 이 저장소에 추가하거나 배포하지 않는다. Git 제외 규칙은 실수를 줄이는 장치이며 실제 운영 환경의 삭제 처리를 대신하지 않는다.
